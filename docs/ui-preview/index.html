本次优化点（相对当前 HomeView）

  • 快速连接区：从「扁平容器 + 17px 输入框」升级为分组卡片 + 34px 输入框（接近系统 large 控件），内嵌设备图标与「回车连接」提示，聚焦时系统风蓝色 focus ring；连接按钮用 macOS 标准 accent 纯色填充。
  • Header：使用 FarPane 图形标和字标，服务器按钮变为带状态指示点的按钮（未配置橙色 / 已配置绿色），标题降为 24px 页面级字号。
  • 设备列表：每行增加低调的设备类型图标（灰底圆角方块），行距更宽松，悬停整行浅色高亮（同系统设置列表）；ID 等宽数字字体；已验证设备显示绿色徽标。
  • 原生感：去掉毛玻璃、强阴影、渐变背景与发光装饰；背景为纯 windowBackgroundColor，控件尺寸、圆角、focus ring 对齐 macOS 系统控件。
  • 细节：状态点、版本号胶囊、空状态图标、滚动条样式，所有控件带 hover/active 反馈。

💡 深色模式自动生效（系统切换即可预览）。此稿确认后，我会按此视觉在 HomeView.swift 中用 AppKit 等价 API 还原（NSTextField + NSButton + NSVisualEffectView 仅在窗口层）。
