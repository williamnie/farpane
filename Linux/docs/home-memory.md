## 共享页对照

此前 99–106 MiB 的首页样本使用隔离镜像中的 GTK/Mesa/字体文件。实查其中六个主要文件与 linux-host 系统文件 SHA-256 完全相同，但设备/inode 不同，无法与宿主桌面按同一文件页分摊 PSS。

新增 `run-native-gpu-test.py --shared-runtime-pages` 只读挂载六个字节完全相同的系统文件：LLVM、Gallium、GTK4、libadwaita、Noto CJK 常规和粗体。运行前逐文件比较镜像/宿主哈希和大小，任何不一致即拒绝；运行后核对宿主文件未变，实际 GUI smaps 的设备/inode 也逐项匹配。没有挂载宿主显示、服务、用户目录或配置，也没有安装/替换系统库。这个模式只用于本机归因，不是可移植的产品启动方式。

| 条件（同一 `.5` 二进制） | 两次首页 PSS MiB | 解释 |
| --- | --- | --- |
| 镜像文件，默认分配器 | 104.80 / 98.83 | 原隔离口径的同轮对照 |
| 相同内容的系统文件页，默认分配器 | 78.96 / 78.12 | 文件页分摊改变，应用没有修改 |
| 相同系统文件页，固定大块分配阈值 | 75.58 / 74.77 | 仅测试 GUI 进程的分配器诊断选项 |

第三组使用 `MALLOC_MMAP_THRESHOLD_=131072` 和 `MALLOC_TRIM_THRESHOLD_=131072`；未作为产品默认。六次短时连接都验证实际 AMD Radeon 780M/radeonsi/ACO、VAAPI、DMA-BUF、GTK 呈现和 Viewer 回收，没有软件帧回退。它们仍是 256×128 静态夹具，不是吞吐、真实桌面或配对旧版 A/B。

## 首页独立空闲测量

新增 `--home-memory`：启动真实 `.5` 首页，保持 30 秒，在 3/10/30 秒读取 `/proc`；不创建 Viewer，不截图导出额外纹理，不为采样强制 trim。应用原有两秒后一次后台 trim 保持启用。只有私有 Wayland、普通用户 GUI 和合成 Host，宿主服务保持原状。

| 相同系统文件页条件 | 30 秒 GUI PSS | GUI USS | 3–30 秒 CPU（单核） | FD / 子进程 |
| --- | --- | --- | --- | --- |
| 默认分配器 | 78.42 MiB | 60.44 MiB | 0.074% | 12 / 0 |
| 固定大块分配阈值诊断 | 75.45 MiB | 57.69 MiB | 0.037% | 12 / 0 |

默认样本 3 秒为 78.52 MiB，30 秒为 78.42 MiB；仅等待更久没有出现明显下降。两个条件 SwapPss 均为 0，FD 没有增长。线程数在后台编译线程退出后均为 20。默认条件达到本次隔离 GUI 空闲 CPU ≤0.5% 的采样目标；CPU 差异只有一个时钟 tick，不能据此声称分配器策略降低 CPU。

分配器诊断的稳态差值约 3 MiB，仍不足以达到 60 MiB。它尚未通过图片传输、软件回退、长期交互及所有最低环境的性能回归，因此保留为测试选项。没有仅为了该数字新增产品分配器设置、关闭 GPU 或改变页面功能。

同时保留按 DRM client 去重的原始 fdinfo。默认首页样本记录 GTT 驻留约 34.02 MiB、VRAM 驻留约 46.73 MiB，3–30 秒图形引擎计数不再增加。这些数值单独报告，不能直接与 PSS 相加；PSS 不包含完整图形分配，部分系统映射又可能与 GTT 重叠。本轮没有把内存转移到 GPU 来降低 PSS。

## 复现与范围

```sh
python3 -B Scripts/linux/run-native-gpu-test.py --viewer \
  --artifact Build/Linux/artifacts/farpane-native-dev-5ad72a016972fad57d895c5e \
  --memory-probe identity --shared-runtime-pages --home-memory
```

省略 `--home-memory` 执行原短时两次 GPU 连接；省略 `--shared-runtime-pages` 使用原镜像文件；`--memory-probe mmap128k` 仅给测试 GUI 设置上面的分配器参数。所有模式仍使用 GPU 锁、限定 renderD128、单路低负载。当前默认连续检查已安装原生 Host 的连接、待审批、文件工作和媒体资源；任何活动或未知状态只停止本次私有探针。历史旧版 Host 的视频数路径需显式 `--legacy-host`，不自动降级。

五次探针合计 595 次空闲检查均为零，均成功退出。只有六文件页共享，其他运行库仍来自原镜像，合成器也是私有 Weston；因此这不是宿主 GNOME/KDE、实际安装或全部进程总预算验收。不能把本轮 78 MiB 换成原 60 MiB 门槛。首页仍需实际桌面确认、分配归因与进一步优化，组合预算和配对 A/B 仍待维护窗口。

完整日志、smaps、DRM、实际二进制和文件页身份见[首页测量证据](../../Evidence/LinuxHost/2026-10-17-native-home-memory/README.md)。`.5` 候选和现有安装保持不变，新增代码仅为 Linux 测试与诊断入口。
