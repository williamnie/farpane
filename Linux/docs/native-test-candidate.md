## 已接通的功能

- 首页：本机 ID/认证状态、服务器与固定密码设置、GPU 状态、入站审批与撤权、设备收藏/别名/搜索、系统密码库。
- 会话：真实认证与视频呈现、VAAPI/EGL GPU 路径及软件兼容模式、键鼠/中文输入、显示器选择、HUD、主动断开与有界自动重连。
- 共享：音频开关/音源选择、分类和双向剪贴板、文件及目录上传下载、批准/覆盖确认、取消与进度。
- 生命周期：关闭 GUI 后保留 Host，独立 Viewer worker，通知/托盘/D-Bus 激活，网络与登录会话恢复，安装、升级和回退事务。

这些能力有源码实现和隔离测试记录；真实桌面、跨平台和完整故障矩阵仍有未验收项，详见 [gui-status.md](gui-status.md)。不能仅凭以上列表认定所有发行版都可用。

## 切换和用户测试

包管理器安装仅暂存候选；实际启动使用原子切换后的不可变 release。维护切换会中断旧 FarPane 会话，需先确认测试窗口，再执行 [安装合同](native-install.md)中的 stage、plan、activate 与普通用户入口 bind。所有命令绑定上表的确切新旧版本，不应直接从候选目录启动 GUI，或手动替换当前正在运行的二进制。

维护窗口内先核对 ID、服务器、固定密码状态和 GPU 设置；仅切换 FarPane，保留上表旧版用于回退。随后建议用户依次验证：

1. Mac mini 用原先的 FarPane ID 和自己设置的固定密码连接 hermes；确认画面、键鼠、中文输入与 GPU 后端。
2. 关闭 Linux GUI，确认已经建立的被控连接继续；重新打开，检查审批/撤权和状态。
3. Linux 发起一次出站连接，检查密码流程、画面/全屏、音频、文本/图片剪贴板和文件传输。
4. 主动断开后重新连接；核对设备历史、收藏和服务器设置仍在。

若出现身份变化、连接失败或画面问题，保留日志并按维护事务回退；不覆盖用户密码、不重新生成身份、不切换原 RustDesk。
