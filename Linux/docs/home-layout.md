每组通过外部鼠标操作三页导航，观察设备页、授权页、共享页、服务器设置、关闭弹窗后页面、设备页底部和关于页。服务器字段与保存按钮可见，Escape 返回成功，滚动后最近设备区可见，关于页版本可见。保存按钮只检查呈现，不执行配置写入。每组结束核对设备 ID、服务器、修订号、Host/GPU 开关和入站状态未变；GUI 退出后 PID 完整消失。

28 份 GTK 几何记录中的标签/输入框/按钮没有横向超出窗口；标签没有省略或缺字。长页纵向滚动区域以外的控件仍可能处于 mapped 状态，所以 `outside_window` 计数不是裁切缺陷数量，观察器也不判定全部祖先剪裁或遮挡。实际查看了默认尺寸弹窗和小窗口 1×/2× 截图，关键按钮可见。没有声称全部控件均可见或全部操作均已覆盖。

首轮 `run-pdcyab97` 在关于页失败：测试误以为 comments 出现在第一页，而本镜像 libadwaita 将其放在 Details 子页。截图显示正常的品牌、版本和 Details 入口；将断言改为首屏版本可见后，`run-i1i044yv` 四组通过。失败与成功的源码、输出和截图均保留，未修改应用来满足测试。
