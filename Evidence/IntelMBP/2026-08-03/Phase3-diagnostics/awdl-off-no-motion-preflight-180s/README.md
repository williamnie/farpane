# Phase 3 AWDL-off preflight without continuous motion

This real 180-second Hermes relay diagnostic was run after AWDL was disabled on
the Intel MacBook Pro. The dedicated 30Hz motion source had already expired, so
the run did not provide continuous full-frame motion and must not be represented
as acceptance evidence.

Network delay and frame rates improved relative to the earlier AWDL-active run,
but the 27.20 encoded FPS and 24.26 presented FPS did not pass the 4K preflight
gate. A fresh preflight with the motion source running is required. Connection
credentials and endpoint identifiers are not recorded.
