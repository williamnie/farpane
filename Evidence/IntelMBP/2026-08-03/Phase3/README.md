# Phase 3 Intel acceptance evidence

This directory contains the successful 30-minute real Hermes relay run from
the Intel MacBook Pro to the 4096x2304 Mac mini. Functional checks in the
report were marked only after visible remote feedback. No fixture result is
represented as live evidence, and connection credentials are not recorded.

`pipeline-validation.txt` covers the H265/VideoToolbox/Metal performance and
stability gates. `functional-validation.txt` covers pointer, buttons, wheel,
keyboard, full screen, HUD, sanitized error UI and remote-feedback checks.
